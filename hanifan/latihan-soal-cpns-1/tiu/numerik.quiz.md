# problem:multiple_choice

## question

Jika $\frac{y}{7} + \frac{y}{5} = \frac{12}{35}$, maka nilai $y$ sama dengan...

## option:correct

$1$

## option

$\sqrt{6}$

## option

$12$

## option

$16$

## explanation

Kalikan kedua ruas dengan KPK dari $7$ dan $5$, yaitu $35$:

$$5y + 7y = 12$$
$$12y = 12 \implies y = 1$$

Polanya adalah bilangan sebelumnya ditambah $(\text{bilangan prima} + \text{kuadrat bilangan prima tersebut})$:

# problem:multiple_choice

## question

Uang Amir $\text{Rp }20.000$ lebih banyak daripada uang Budi ditambah dua kali uang Hasan. Total uang Amir, Budi, dan Hasan adalah $\text{Rp }100.000$. Selisih uang Budi dan Hasan adalah $\text{Rp }5.000$. Uang Amir adalah...

## option

$\text{Rp }22.000$

## option

$\text{Rp }33.000$

## option

$\text{Rp }51.000$

## option:correct

$\text{Rp }67.000$

## explanation

Diketahui:
1. $A = 20.000 + B + 2H$
2. $A + B + H = 100.000$
3. $B - H = 5.000 \implies B = H + 5.000$

Substitusikan (1) ke (2):
$$(20.000 + B + 2H) + B + H = 100.000 \implies 2B + 3H = 80.000$$

Substitusikan $B = H + 5.000$:
$$2(H + 5.000) + 3H = 80.000 \implies 5H = 70.000 \implies H = 14.000$$

Maka $B = 19.000$, dan $A = 100.000 - 19.000 - 14.000 = \text{Rp }67.000$.

# problem:multiple_choice

## question

Ibu A membayar $\text{Rp }10.700$ untuk $4$ bungkus mie instan dan $3$ kaleng susu kental manis. Ibu B membayar $\text{Rp }14.900$ untuk $3$ bungkus mie instan dan $5$ kaleng susu kental manis. Berapakah harga sebungkus mie instan?

## option

$\text{Rp }950$

## option:correct

$\text{Rp }800$

## option

$\text{Rp }750$

## option

$\text{Rp }700$

## explanation

Misalkan mie instan $= x$ dan susu $= y$:

- $4x + 3y = 10.700 \quad (\times 5) \implies 20x + 15y = 53.500$
- $3x + 5y = 14.900 \quad (\times 3) \implies 9x + 15y = 44.700$

Kurangkan kedua persamaan:
$$11x = 8.800 \implies x = \text{Rp }800$$

# problem:multiple_choice

## question

Ani membeli $2\text{ kg}$ apel, $2\text{ kg}$ anggur, dan $1\text{ kg}$ jeruk seharga $\text{Rp }67.000$. Nia membeli $3\text{ kg}$ apel, $1\text{ kg}$ anggur, dan $1\text{ kg}$ jeruk seharga $\text{Rp }61.000$. Ina membeli $1\text{ kg}$ apel, $3\text{ kg}$ anggur, dan $2\text{ kg}$ jeruk seharga $\text{Rp }80.000$. Harga $1\text{ kg}$ apel, $1\text{ kg}$ anggur, dan $4\text{ kg}$ jeruk seluruhnya adalah...

## option

$\text{Rp }37.000$

## option

$\text{Rp }44.000$

## option:correct

$\text{Rp }51.000$

## option

$\text{Rp }55.000$

## explanation

Jumlahkan persamaan belanja Ani dan Nia:
$$(2a + 2b + c) + (3a + b + c) = 67.000 + 61.000 \implies 5a + 3b + 2c = 128.000$$

Kurangkan dengan belanja Ina ($a + 3b + 2c = 80.000$):
$$4a = 48.000 \implies a = 12.000$$

Diperoleh $b = 19.000$ dan $c = 5.000$. Maka:
$$a + b + 4c = 12.000 + 19.000 + 4(5.000) = \text{Rp }51.000$$

# problem:multiple_choice

## question

Dua buah lingkaran masing-masing memiliki diameter $40\text{ cm}$ dan $10\text{ cm}$. Berapa selisih luas kedua lingkaran tersebut ($\pi = 3,14$)?

## option

$2.826\text{ cm}^2$

## option

$4.710\text{ cm}^2$

## option:correct

$1.177,5\text{ cm}^2$

## option

$942,5\text{ cm}^2$

## explanation

Jari-jari lingkaran pertama $r_1 = 20\text{ cm}$ dan kedua $r_2 = 5\text{ cm}$:

$$\text{Selisih luas} = \pi(r_1^2 - r_2^2) = 3,14 \times (20 + 5)(20 - 5) = 3,14 \times 25 \times 15 = 1.177,5\text{ cm}^2$$
