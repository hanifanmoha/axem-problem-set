## 1. Analogi

Analogi menguji kemampuan menemukan kesetaraan hubungan antar-kata.

### Langkah Mengerjakan Soal Analogi
1. Ubah pasangan kata menjadi kalimat spesifik yang menghubungkan keduanya.
2. Pastikan urutan dan jenis kata (kata benda, kata sifat, kata kerja) pada jawaban sejajar dengan soal.
3. Cocokkan dengan pola hubungan umum berikut:

| Jenis Hubungan | Contoh Pasangan Kata | Penjelasan Hubungan |
| :--- | :--- | :--- |
| **Kebutuhan** | `gelap : sinar = lapar : makanan` | Gelap butuh sinar; lapar butuh makanan |
| **Kumpulan / Bagian** | `bunga : buket = kertas : buku` | Buket tersusun dari bunga; buku dari kertas |
| **Sebab - Akibat** | `penghormatan : jasa = insentif : prestasi` | Berjasa diberi penghormatan; berprestasi diberi insentif |
| **Sinonim / Antonim** | `adagio : allegro = lambat : cepat` | Adagio berarti lambat; allegro berarti cepat |
| **Proses** | `kayu : serut = kebun : cangkul` | Kayu diserut; kebun dicangkul |
| **Kegunaan** | `fotosintesis : cahaya = cetak : tinta` | Cahaya untuk fotosintesis; tinta untuk cetak |
| **Bahan Baku** | `beras : nasi goreng = kayu : kursi` | Nasi goreng berbahan beras; kursi berbahan kayu |
| **Tempat & Fungsi** | `guru : sekolah : murid = gembala : padang rumput : domba` | Profesi, tempat kerja, dan objeknya |

## 2. Silogisme (Penalaran Logis)

Peserta wajib menarik kesimpulan murni berdasarkan premis yang diberikan tanpa memasukkan opini pribadi.

### Aturan Penarikan Kesimpulan
1. **Modus Ponens**
   - Premis 1: $p \Rightarrow q$ *(Jika Mandalika lulus ujian, maka ia mendapat beasiswa)*
   - Premis 2: $p$ *(Mandalika lulus ujian)*
   - **Kesimpulan:** $q$ *(Ia mendapat beasiswa)*
2. **Modus Tollens**
   - Premis 1: $p \Rightarrow q$ *(Jika Mandalika lulus ujian, maka ia mendapat beasiswa)*
   - Premis 2: $\sim q$ *(Mandalika tidak mendapat beasiswa)*
   - **Kesimpulan:** $\sim p$ *(Mandalika tidak lulus ujian)*
3. **Silogisme Hipotetis**
   - Premis 1: $p \Rightarrow q$
   - Premis 2: $q \Rightarrow r$
   - **Kesimpulan:** $p \Rightarrow r$

### Perbedaan Kuantor Logika
- **"Semua" / "Setiap":** Berlaku untuk seluruh anggota himpunan tanpa terkecuali.
- **"Beberapa" / "Ada" / "Sementara" / "Sebagian":** Berlaku untuk minimal satu anggota (tidak harus seluruhnya).

## 3. Penalaran Analitis

Menguji kemampuan menyusun informasi dari teks cerita ke dalam model urutan, perbandingan, syarat, atau kombinasi.

### A. Model Urutan & Perbandingan
Gunakan notasi matematika untuk menyederhanakan cerita:
- **"Kurang dari"** $\rightarrow$ tanda $<$
- **"Lebih dari"** $\rightarrow$ tanda $>$
- **"Sama dengan / sama banyaknya"** $\rightarrow$ tanda $=$

**Contoh Hubungan Urutan:**
- Jika $A < B$ dan $B < C$, maka pasti $A < C$ ($A < B < C$).
- Jika $A < B$ dan $B > C$, maka hubungan antara $A$ dan $C$ **tidak dapat ditentukan** tanpa informasi tambahan.

### B. Hubungan Antarsyarat
- **Syarat Cukup ($P \Rightarrow Q$):** Terjadinya $P$ sudah cukup menjamin terjadinya $Q$. *(Contoh: Budi bujangan cukup untuk memastikan ia belum menikah).*
- **Syarat Perlu:** $Q$ mutlak diperlukan agar $P$ bisa terjadi. *(Contoh: Belum menikah adalah syarat perlu untuk status bujangan).*
- **Syarat Mutlak ($P \Leftrightarrow Q$):** Berlaku dua arah ("jika dan hanya jika"). *(Contoh: Air turun dari langit jika dan hanya jika terjadi hujan).*

### Tips Cepat Penalaran Analitis
1. Tandai kata kunci pembatas (misalnya: *tidak boleh berdekatan*, *harus di ujung*, *sebelum/sesudah*).
2. Buat sketsa tabel atau garis urutan sederhana.
3. Gunakan teknik eliminasi opsi jawaban untuk menghemat waktu.
